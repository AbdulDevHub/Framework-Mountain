# 🏔️ Portfolio Mountain

Welcome to **Portfolio Mountain**, a growing collection of portfolio websites I’ve built either **from scratch** or by **following and customizing YouTube tutorials**.

Each folder in this repository represents a complete portfolio project with its own tech stack, structure, and design style. This repo exists both as:

- a **learning log** 📒  
- and a **visual archive** of my progress as a developer 🚀

---

## 📂 Projects

### 🌌 Black Hole

A modern, animated developer portfolio built with **Next.js**, **TypeScript**, and **Tailwind CSS**.  
Features smooth animations, video backgrounds, and a futuristic space aesthetic.

**Tech highlights:**

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Component-driven architecture
